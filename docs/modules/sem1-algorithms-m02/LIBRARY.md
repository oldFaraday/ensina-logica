## 2. "Praticar este trecho"

Cada seção (`##`) das cinco unidades exibe o botão **"Praticar este trecho"** quando a unidade tem `linked_lessons`. O botão:

1. leva à lição vinculada à unidade (`l04`, `l05` ou `l06`);
2. mostra os exercícios daquela lição, na ordem didática;
3. permite voltar à biblioteca pelo botão **Voltar** da própria lição.

Mapeamento unidade → lição:

| Unidade | Lição aberta pelo botão |
|---------|--------------------------|
| `th-sem1-algorithms-m02-constants-variables` | `l04` |
| `th-sem1-algorithms-m02-identifier-names` | `l04` |
| `th-sem1-algorithms-m02-data-types` | `l05` |
| `th-sem1-algorithms-m02-expressions-operators` | `l06` |
| `th-sem1-algorithms-m02-integer-division-modulus` | `l06` |

> As duas primeiras unidades compartilham a lição `l04`; as duas últimas compartilham a lição `l06`. A lição mostra todos os exercícios daquela lição, inclusive os das duas unidades.

## 4. Acessibilidade e idioma

- Todo o conteúdo está em `pt-BR`; os termos originais em inglês aparecem entre parênteses na primeira ocorrência.
- As unidades usam apenas texto; nenhuma imagem da fonte foi copiada ou adaptada.
- Os blocos de pseudocódigo usam a linguagem `pseudo` e não pressupõem sintaxe de Python, C++, Java ou qualquer outra linguagem.
- Os cálculos dos exercícios foram conferidos em Python 3.15.0 apenas como verificação interna; o aluno não precisa executar código.
