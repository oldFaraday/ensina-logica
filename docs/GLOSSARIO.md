# Glossário Canônico — Ensina Lógica

Vocabulário canônico inglês → português (PT-BR) usado em todo o conteúdo do
1º semestre (Algoritmos e Lógica de Programação e Matemática Discreta).

## Regras de uso

1. **Primeira ocorrência** de cada termo traz o original em inglês entre
   parênteses, ex.: *vetor (array)*.
2. **Não use "arranjo"** para *array* em contexto de programação — colide com
   combinatória (arranjo = permutation with repetition).
3. Mantenha o mesmo termo PT-BR em ambas as disciplinas para um mesmo conceito
   em inglês.
4. Este glossário é a fonte da verdade para i18n e revisão de conteúdo.

---

## A

**abstract data type (ADT)** → tipo abstrato de dados
Modelo matemático de um tipo de dado definido pelas operações que expõe, independentemente de como é implementado internamente.

**algorithm** → algoritmo
Sequência finita e ordenada de passos bem definidos que resolve um problema ou realiza uma tarefa.

**array** → vetor
Coleção indexada de elementos do mesmo tipo, armazenados em posições contíguas de memória. *Não usar "arranjo" em contexto de programação.*

**assertion** → afirmação / asserção
Expressão booleana que se espera verdadeira em um dado ponto do programa; usada em provas de corretude.

**assignment** → atribuição
Operação que armazena um valor em uma variável.

**asymptotic notation** → notação assintótica
Família de notações (Big-O, Big-Ω, Big-Θ) que descreve o crescimento de funções, usado para analisar complexidade de algoritmos.

---

## B

**base case** → caso base
Caso mais simples de uma definição ou prova recursiva, que não recorre à própria definição.

**big-O notation** → notação big-O
Limite superior assintótico do crescimento de uma função; expressa o pior caso de tempo ou espaço de um algoritmo.

**binary** → binário
Sistema de numeração de base 2, usando apenas os dígitos 0 e 1.

**boolean** → booleano
Tipo de dado com dois valores possíveis: verdadeiro (true) ou falso (false).

**bound** → limite / fronteira
Valor que restringe o domínio de uma variável ou a execução de um laço.

---

## C

**constant** → constante
Identificador cujo valor não muda durante a execução do programa.

**conditional** → condicional
Estrutura de controle que executa um bloco somente se uma condição for verdadeira (ex.: se/senão).

**conjunction** → conjunção
Conectivo lógico "e" (∧): verdadeiro quando ambos os operandos são verdadeiros.

**constant time** → tempo constante
Complexidade O(1): o tempo de execução não depende do tamanho da entrada.

**constructor** → construtor
Método especial que inicializa um objeto no momento de sua criação.

**control flow** → fluxo de controle
Ordem em que as instruções de um programa são executadas, incluindo sequências, condicionais e laços.

**data type** → tipo de dado
Categoria de valores que determina quais operações podem ser feitas e como os valores são armazenados.

**debugging** → depuração
Processo de encontrar e corrigir erros (bugs) em um programa.

**discrete mathematics** → matemática discreta
Ramo da matemática que estuda objetos discretos (inteiros, grafos, proposições, conjuntos) em vez de contínuos.

**disjunction** → disjunção
Conectivo lógico "ou" (∨): verdadeiro quando pelo menos um dos operandos é verdadeiro.

---

## D

**edge** → aresta
Conexão entre dois vértices em um grafo.

**else** → senão
Ramo de um condicional executado quando a condição é falsa.

**empty set** → conjunto vazio
Conjunto que não contém nenhum elemento; denotado por ∅ ou {}.

**encapsulation** → encapsulamento
Princípio de agrupar dados e métodos que os manipulam em uma única unidade, ocultando detalhes internos.

**end condition** → condição de término
Condição que, quando verdadeira, encerra um laço de repetição.

**equivalence** → equivalência
Relação entre duas expressões que têm o mesmo valor de verdade em todas as atribuições possíveis.

**execution** → execução
Processo pelo qual o computador interpreta e realiza as instruções de um programa.

---

## E

**false** → falso
Valor booleano que indica a negação de verdade.

**finite** → finito
Conjunto ou sequência com número limitado de elementos.

**first-class** → de primeira classe
Entidade (função, dado) que pode ser passada como argumento, retornada e atribuída a variáveis como qualquer outro valor.

**flowchart** → fluxograma
Representação gráfica de um algoritmo usando símbolos padronizados (terminal, processo, decisão, entrada/saída).

**function** → função
Bloco de código reutilizável que recebe parâmetros, executa operações e pode retornar um valor.

---

## F

**graph** → grafo
Estrutura composta por vértices (nós) e arestas que conectam pares de vértices.

**greedy** → guloso
Estratégia de algoritmos que faz a escolha localmente ótima em cada passo, esperando chegar a uma solução globalmente ótima.

---

## I

**if** → se / se então
Palavra-chave que inicia uma estrutura condicional.

**implication** → implicação
Conectivo lógico "se … então" (→): falso apenas quando a hipótese é verdadeira e a conclusão é falsa.

**index** → índice
Posição de um elemento em um vetor, string ou outra estrutura indexada.

**induction** → indução
Método de prova que estabelece um caso base e mostra que, se a afirmação vale para um caso, vale para o próximo.

**infinite** → infinito
Conjunto ou sequência sem número limitado de elementos.

**input** → entrada
Dados fornecidos a um programa ou algoritmo para processamento.

**integer** → inteiro
Número sem parte fracionária (…, -2, -1, 0, 1, 2, …).

---

## L

**loop** → laço
Estrutura de repetição que executa um bloco de código enquanto uma condição for verdadeira (ex.: while, for).

**logic** → lógica
Estudo sistemático do raciocínio válido, incluindo proposições, conectivos e quantificadores.

---

## M

**matching** → emparelhamento
Conjunto de arestas em um grafo tal que nenhum vértice é tocado por mais de uma aresta escolhida. Usado em algoritmos de alocação e pareamento.

**module** → módulo
Unidade de organização de código que agrupa funções, tipos e variáveis relacionadas.

---

## N

**negation** → negação
Conectivo lógico "não" (¬): inverte o valor de verdade de uma proposição.

**nested loop** → laço aninhado
Laço de repetição contido dentro de outro laço.

**node** → nó / vértice
Elemento fundamental de um grafo ou árvore; armazena dados e referências a outros nós.

**non-deterministic** → não determinístico
Algoritmo ou máquina cujos passos podem ter múltiplos desdobramentos possíveis para o mesmo estado.

---

## O

**object** → objeto
Entidade que agrupa estado (atributos) e comportamento (métodos).

**operand** → operando
Valor sobre o qual um operador incide.

**operator** → operador
Símbolo que representa uma operação (aritmética, lógica, relacional).

**order of growth** → ordem de crescimento
Taxa com que o tempo ou espaço de um algoritmo cresce com o tamanho da entrada.

**output** → saída
Resultado produzido por um programa ou algoritmo.

---

## P

**parameter** → parâmetro
Variável nomeada na definição de uma função que recebe um valor quando a função é chamada.

**pointer** → ponteiro
Variável que armazena o endereço de memória de outro valor.

**predicate** → predicado
Expressão que contém variáveis e se torna uma proposição quando as variáveis recebem valores.

**proof** → prova
Argumento dedutivo que estabelece a verdade de uma afirmação matemática.

**pseudocode** → pseudocódigo
Descrição de um algoritmo em linguagem próxima ao português/inglês, imitando código, mas sem sintaxe rígida de linguagem de programação.

---

## Q

**quantifier** → quantificador
Operador lógico que especifica a quantidade de elementos para a qual um predicado vale (∀ "para todo", ∃ "existe").

**queue** → fila
Estrutura de dados do tipo FIFO (primeiro a entrar, primeiro a sair).

---

## R

**recursion** → recursão
Técnica em que uma função chama a si mesma para resolver instâncias menores do mesmo problema.

**return** → retorno
Comando que encerra a execução de uma função e opcionalmente devolve um valor ao chamador.

**runtime** → tempo de execução
Período durante o qual um programa está sendo executado pelo computador.

---

## S

**scope** → escopo
Região do programa onde um identificador (variável, função) é reconhecido e pode ser usado.

**selection** → seleção
Estrutura de controle que escolhe entre caminhos alternativos com base em uma condição (if/else).

**sequence** → sequência
Lista ordenada de elementos; também uma das três estruturas de controle da programação estruturada.

**set** → conjunto
Coleção de elementos distintos, sem ordem definida.

**statement** → sentença / declaração
Unidade mínima de ação em um programa; pode ser uma proposição (na lógica) ou uma instrução (na programação).

**string** → string / cadeia de caracteres
Sequência de caracteres usada para representar texto.

**struct** → struct / registro
Tipo de dado composto que agrupa campos de tipos possivelmente diferentes.

**syntax** → sintaxe
Conjunto de regras que define como escrever programas válidos em uma linguagem.

---

## T

**theorem** → teorema
Afirmação matemática cuja verdade foi demonstrada por meio de uma prova.

**time complexity** → complexidade de tempo
Medição do tempo que um algoritmo leva para ser executado em função do tamanho da entrada.

**true** → verdadeiro
Valor booleano que indica a afirmação de um fato.

**truth table** → tabela-verdade
Tabela que lista todas as combinações possíveis de valores de verdade das variáveis e o resultado de uma proposição molecular.

---

## V

**variable** → variável
Identificador que representa um valor armazenado na memória, podendo mudar durante a execução.

**vertex** → vértice
Elemento fundamental de um grafo, também chamado de nó; representa uma entidade ou ponto.

---

## W

**while** → enquanto
Palavra-chave que inicia um laço de repetição condicional (testa antes de executar).

---
